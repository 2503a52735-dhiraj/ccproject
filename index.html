Connecting AWS Learner Lab to this Dashboard (3 Simple Steps)
1
Create the AWS Lambda Function in AWS Academy Learner Lab:

Log into AWS Learner Lab, open the AWS Console in us-east-1, search for Lambda, and click Create function:

  • Function name: IoTButtonHandler
  • Runtime: Python 3.12
  • Execution role: Choose "Use an existing role" → Select "LabRole" (mandatory in AWS Learner Lab).
2
Enable Function URL (Direct Public HTTPS Endpoint):

Go to your function's Configuration tab → click Function URL → Create function URL:

  • Auth type: NONE
  • Check "Configure cross-origin resource sharing (CORS)" (Allow origin: *, Methods: POST, OPTIONS)
  • Click Save and copy your new Function URL (e.g., https://xxxx.lambda-url.us-east-1.on.aws/).
3
Paste the Code & Connect:

Copy the code from aws_lambda_handler.py (or click the button below), paste it into the Lambda Code editor in AWS, and click Deploy.

Then paste your Function URL into the dashboard input and click Apply! Every button press will now trigger your real AWS Lambda in AWS Learner Lab.
